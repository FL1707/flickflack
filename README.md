# Flickflack

Turn-News-App für Kinder (Gerätturnen, Trampolin, Rhythmische Sportgymnastik), veröffentlicht über GitHub Pages.

- `index.html`: die komplette App (HTML, CSS, JS) mit den Tabs News, Ergebnisse, Upcoming, Training, Quiz, Game und Statistik
- `data.json`: alle tagesaktuellen Inhalte; wird jeden Morgen um 6:00 Uhr von einer geplanten Claude-Code-Aufgabe neu geschrieben (Anleitung: `werkzeuge/AUFGABE.md`)
- `training.json`: DTB-Pflichtübungen Gerätturnen männlich AK 11/12 (Stand 15.03.2025), FAQ (12.06.2026), Küranforderungen AK 12 (15.11.2024), Athletische Tests (11/2024) und Links zu den DTB-Videobeispielen
- `statistik.json`: Turn-Helden, Rekorde und Elemente mit Namen
- `apple-touch-icon.png`: Symbol für den iPad-Home-Bildschirm

Alle Bilder sind selbst gezeichnete Strichfiguren (SVG/Canvas); es werden keine Pressefotos verwendet. Der Fortschritt im Training („Kann ich schon“), Quiz-Antworten und Game-Rekorde werden nur im Browser des Geräts gespeichert.
